# Dictionary pronunciation targets

These are standard dictionary pronunciations for the written words, not claims about the singer's accent or exact sung vowels. The broad respellings in each track guide are arranged for quick use in Suno; use these IPA targets when you want a more precise reference. Stress is marked with ˈ. Where a lyric is a pun, the performance can intentionally depart from the dictionary reading.
